# Security & authorized use

This tool is for **defensive and authorized offensive security** workflows only.

- Maintain a written scope (contract, program rules, or internal approval).
- Run `hx-scope check` or `filter` **before** chaining other HackerX tools.
- Do not use scope files to justify testing unrelated third parties.

Report vulnerabilities in this CLI via GitHub Issues on the HackerX-official repository.
